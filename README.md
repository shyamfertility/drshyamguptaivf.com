# drshyamguptaivf.com

Website for **Dr Shyam N Gupta, MD** — Fertility & IVF Specialist and Gynaecological
Endoscopic Surgeon, Centre Head at Indira IVF, J.P. Nagar, Bengaluru.

Static site, no build step. `index.html` plus `assets/`.

## Deployment
GitHub Pages serves `main` at the repository root. Any push to `main` republishes.
Settings -> Pages -> Source: "Deploy from a branch", Branch: `main`, folder: `/ (root)`.

## Custom domain
Add a `CNAME` file containing `www.drshyamguptaivf.com` once DNS points here.

## Editing
Photographs and articles are stored in the page itself. To add either, use the
editable version and re-export — do not hand-edit the markup.
